📚 Architecture Principles

  • Client-Server Separation: React only calls FastAPI, never directly accesses jobs sites, Excel, or AI
  • Centralized Data Model: Job, Run, ApplicationStatus defined once in Phase 1, used everywhere
  • Code/AI Boundary: Code owns state/persistence/retries/coverage; AI only invoked for well-defined work units with structured schemas
  • Shared Services: Dedup, Application Gate, Coverage used by both Task 1 and Task 2
  • MVP Scope: Greenhouse, Lever, Comeet, Generic adapters only; broader sources deferred to V1
  • DATA_DIR Pattern: External canonical files (Excel, markdown) loaded via environment variable
